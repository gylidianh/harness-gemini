# Harness Gemini

Windows desktop app for local chat, image generation, coding, and browsing.

## Download

Get `Harness-Gemini-1.0.0-win-x64.exe` from the [Releases](../../releases) page.
It is a portable build: download and run, no installation needed.

## Notes

- Version: 1.0.0
- Platform: Windows x64
- Your settings, API keys and chat history are stored locally on your own computer and are not part of this download.
- The executable is not code-signed, so Windows SmartScreen may show a warning on first launch.
