# Harness Gemini 2.0.5

- 手机远程新增**会话正文阅读**：点击「会话」列表或「待办 → 进行中」卡片的「查看正文」，即可在手机端查看历史对话与正在流式生成的回复正文，支持向上加载更早消息、长文分片续读 / 展开全文、按需查看思考过程、停止生成与底部快捷追问。
- 零协议破坏分片方案：保持原有 8 KiB 明文 / 12 KiB 信封协议上限不变，已部署的 VPS 中继 `server.mjs` 和 `relay-protocol.mjs` 无需修改；响应预留 300B 包裹空间，正文按真实 UTF-8 JSON 字节预算（约 7.5 KiB）二分切片并在 Unicode 码点边界对齐，避免截断 emoji 与 UTF-16 代理对。
- 生成中回复每 2.5 秒增量追尾，仅拉取新增文本片段；严格白名单投影，不暴露工具原始输出、参数、密钥或附件二进制；内置转义安全 Markdown 渲染并将本地图片产物显示为电脑端查看提示。
- 使用自建 VPS 中继时，只需覆盖更新 `relay-server/phone.html` 并刷新手机页面；免服务器直连（局域网 / Cloudflare 隧道）安装新版后直接生效。

退出旧版后运行 Windows x64 安装包即可升级。可用随附的 `SHA256SUMS.txt` 核对安装包和源码压缩包。
