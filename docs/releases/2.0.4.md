# Harness Gemini 2.0.4

- 推理等级扩展为完整 5 档（`minimal` 极低、`low` 低、`medium` 中、`high` 高、`xhigh` 超高），按模型实际能力精确区分支持范围（如 Gemini 4 Neon / Hydrogen、GPT-5.2+ / GPT-6+、Claude 4.7+ / 5+ 支持 `xhigh`；Gemini 4 Carbon 上限为 `high`；Gemini 3.5 Flash-Lite、GPT-5 支持 `minimal`）。
- 切换模型时保留连接所选推理档位；若当前模型不支持该极值档位，界面清晰标注并在请求前自动钳位到最近的支持档位（例如 `xhigh → high`、`minimal → low`），避免无谓报错。
- 完善多协议线上传参、拒参识别与回退链：Gemini Chat 兼容层支持 `reasoning_effort` 与 Google 官方 `extra_body.google.thinking_config` 自动回退；Anthropic `xhigh` 自适应思考默认 `max_tokens` 提升至 `64_000` 并支持阶梯回退；`xhigh` 首字超时窗口扩展至 600 秒。
- 兼容保留 Gemini 3/4 OpenAI 兼容工具调用中的 `extra_content.google.thought_signature`，修复多轮工具调用思考签名丢失问题。
- 修复切换极低/超高档位时提示文案异常及流式输出覆盖 `info` 级别回退提示的问题。

退出旧版后运行 Windows x64 安装包即可升级。可用随附的 `SHA256SUMS.txt` 核对安装包和源码压缩包。
