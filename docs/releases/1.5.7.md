# Harness Gemini 1.5.7

本次为包含代理错误分类修复的 1.5.7 重打包版本，也保留会话删除清理修复。

## 代理错误分类与重试

- 不再仅因错误消息包含 TLS / SSL 就判定证书验证失败。按具体错误码和原因链区分证书、认证、连接重置、超时等错误。
- ECONNRESET、临时连接中断及 TLS 握手断开进入原有有限传输重试，默认最多 6 次尝试（5 次重试）；取消时停止，已有正文时不从头重放。
- 认证阶段超时不再误判为凭据拒绝；真正的证书验证失败、明确 HTTP 407 / SOCKS 认证拒绝及原因链中的永久错误不重试。
- TLS 证书校验保持开启，不静默切换直连，代理提示不暴露代理凭据。

## 会话删除与清理报告

- 区分会话记录删除与工作目录、关联图片、文件改动快照等数据清理。
- 清理失败返回部分成功和具体失败项，不再误报完全成功，也不把记录已删除误报为完全失败。
- 删除前保存清理回执，支持记录已删除后的重复清理与重启后重试。
- 前端仅在后端确认记录删除后移除会话，并显示残留数据清理失败。保留锁定及运行中会话保护。
