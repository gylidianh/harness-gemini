# 常见问题

适用于 Harness Gemini 1.3.10。返回 [项目首页](../README.md) · [使用指南](usage.md)

## 下载后打不开，或提示程序正在运行

确认下载的是 Windows x64 安装包。升级前退出已运行的 Harness Gemini，再运行安装向导。可先按 [使用指南](usage.md#校验安装包) 核对文件校验值。

当前安装包没有代码签名证书，Windows 可能显示发布者或 SmartScreen 提示。请核对下载来源为本项目的 [Releases](https://github.com/gylidianh/harness-gemini/releases)。

## 模型列表读不到怎么办？

检查供应商的接口地址、协议和鉴权信息是否匹配。部分兼容服务不提供模型列表，可以直接填写该服务支持的模型 ID。

模型名称必须与服务端一致；填写一个名称并不会让服务自动支持该模型。

## 为什么没有聊天、编程或生图模式？

模式按当前连接的模型配置显示。在 **设置 → 供应商** 中填写对应模式的模型，然后点击 **保存并使用**。

## 模型切换后，正在生成的回复会更换模型吗？

不会。已开始的任务使用启动时的配置，新选择用于下一条消息。部分操作会在保存或任务处理中暂时禁用。

## 思考等级为什么没有生效？

推理参数由模型与接口共同决定。不支持的模型或生图请求不会按聊天方式发送推理参数；使用 **模型默认** 时由服务端决定。不要仅凭界面中的等级判断服务端实际用了多少推理 token。

## 为什么只看到思考过程，没有正文？

上游可能返回了思考内容，却没有返回回答正文。程序重试后仍失败，会在对应消息中显示原因。请检查模型、协议和服务状态，再重试或切换模型。

## 工作空间怎么不见了？

1.3.10 每次启动默认收起右侧面板。点击顶部右侧的面板按钮即可展开，工作区和已保存产物没有因此删除。

## 新增技能后没有显示怎么办？

进入 **设置 → 技能**，打开技能文件夹，确认技能目录和清单符合该文件夹中的说明，再点击 **刷新**。如果清单读取失败，技能页会显示错误信息。

## 设置中保存的 API Key 去哪了？

已保存的密钥默认以掩码显示，需要时可主动查看。不要将掩码当作新密钥填写；更换密钥时输入完整的新值。密钥使用 Windows 系统密钥保护加密保存。

## 数据是否会经过维护者的服务器？

应用在本机启动界面服务，模型请求发送到你自行配置的服务地址。网页读取、浏览器和下载功能会访问对应站点。你选择的模型服务如何保存请求，应以该服务的政策为准。

发布安装包不携带维护者的本机配置、会话或工作文件。仓库展示截图使用独立演示数据。

## 出错了在哪里查看原因？

先查看失败消息和工具卡中的说明。顶部 **文件 → 打开错误日志** 可打开日志入口，实际文件位于数据目录下的 `logs/errors.log`。

提交问题时附上应用版本、Windows 版本、操作步骤与必要的错误信息。分享前删除密钥、私人对话、本机用户名及其他不需要公开的内容。

## 这个仓库为什么没有完整应用源码？

当前仓库用于安装包发布和用户文档维护。安装包位于 Releases，仓库目录不包含完整应用源码或维护者的本机开发环境，因此没有可直接执行的 `npm install` / 构建步骤。

如果这里没有解决你的问题，请 [提交 Issue](https://github.com/gylidianh/harness-gemini/issues/new/choose)。
